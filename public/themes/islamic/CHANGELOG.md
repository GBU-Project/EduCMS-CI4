# Changelog - EduCMS Theme Islamic

All notable changes to the **EduCMS Theme Islamic** project will be documented in this file.

## [1.0.0] - 2026-07-24

### Added
- Official launch of **EduCMS Theme Islamic v1.0**.
- Generic Theme Engine support in `Template.php` with automatic fallback to core portal views.
- Modular Component Architecture (`views/components/` for Hero, Welcome, Vision, Programs, Stats, Cards, CTA).
- Islamic visual identity: Emerald Green (`#047857`), Forest Green (`#064e3b`), and Gold Accent (`#d97706`).
- Geometric pattern SVG backgrounds and micro-animations.
- Standard metadata `theme.json` and theme activation in **Admin > Theme Website**.
- Complete documentation: `README.md`, `INSTALL.md`, `CUSTOMIZATION.md`.
