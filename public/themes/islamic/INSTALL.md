# EduCMS Theme Islamic - Installation Guide

Follow these steps to activate the **EduCMS Islamic** theme on your EduCMS Core installation.

---

## 🚀 Activation Steps

1. Log in to the administrator panel:
   `http://your-domain.com/admin/login`

2. Go to **Pengaturan Sistem** > **Theme Website** on the sidebar:
   `http://your-domain.com/admin/theme-website`

3. Locate **EduCMS Islamic** in the list of available themes.

4. Select the **EduCMS Islamic** radio button.

5. Click **Simpan Theme Website**.

6. Visit your public website front-page (`/`) to enjoy the new Islamic presentation layer.

---

## 🛠️ Verification & Troublshooting

- **Permissions**: Ensure your server has read permissions for `themes/islamic/`.
- **Cache**: Clear browser cache or hard refresh (`Ctrl + F5`) to reload CSS and JS assets.
- **Reverting to Default**: If you ever wish to return to the default template, simply navigate back to **Admin > Theme Website**, select **EduCMS Default**, and click **Simpan**.
